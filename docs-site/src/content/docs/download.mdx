FolioOrb runs on your machine — no FolioOrb account, hosted app, telemetry, or cloud sync. Download the desktop app for
macOS or Windows below (no Python, no terminal), or [run it in your browser as a local web
app from source](/FolioOrb/build-from-source/) on any platform with Python 3.11+.

[every release](https://github.com/udhawan97/FolioOrb/releases) or use the
[landing page](https://udhawan97.github.io/FolioOrb/) with platform-aware download buttons.

## Release channels

| Channel | Where it comes from | Who it's for |
| --- | --- | --- |
| **Stable** | A version tag (`v5.16.1`), cut manually | Everyone. This is the default download. |
| **latest-main** | Refreshed automatically on every merge to `main` | Testing the newest changes; may be unstable. |

The `latest-main` prerelease has a direct **Development build** link on the website and in
the [releases list](https://github.com/udhawan97/FolioOrb/releases). It always holds a
single, newest build straight from `main`.

<Aside type="caution" title="Early builds are unsigned">
FolioOrb doesn't have a paid Apple or Windows code-signing certificate yet, so macOS
and Windows will show a warning the first time you open it. This is expected for an
open-source app. The [macOS](/FolioOrb/install-macos/) and
[Windows](/FolioOrb/install-windows/) guides show exactly what you'll see and how to
proceed. See [Releases &amp; versioning](/FolioOrb/releases-and-versioning/) for the
signing roadmap.
</Aside>

## Verify your download

Current v5 releases include `SHA256SUMS.txt`. After downloading one platform asset and the
manifest from the same release, confirm that asset matches:

```bash
# macOS — verify only the DMG you downloaded, not the absent Windows asset
grep 'FolioOrb-macOS-arm64-v5.16.1.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
```

```powershell
# Windows PowerShell — compare against the line in SHA256SUMS.txt
Get-FileHash .\FolioOrb-Windows-x64-v5.16.1-Setup.exe -Algorithm SHA256
```

A match detects whether the asset differs from `SHA256SUMS.txt` in that same GitHub
release. Because FolioOrb does not yet publish a configured Minisign signature, this is an
integrity check—not independent proof of who published the manifest.

## Prefer to run from source?

The [install scripts](/FolioOrb/build-from-source/#one-line-install-scripts) and the
[build-from-source](/FolioOrb/build-from-source/) guide support macOS, Windows, and Linux
with Python 3.11+. One-line installs keep their writable profile outside the replaceable
source tree and retain a recovery copy when migrating an older install.
